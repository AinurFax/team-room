# Team Room

Мод для Claude (приложение Claude, вкладка Code, и Claude Code в терминале): совместная работа в «комнатах». У каждой комнаты свои люди, общая память проекта, доска чатов («В работе», «Требует внимания», «Готово»), задачи и лимиты участников. Задачи ведёт сам Claude: берётся за работу — создаёт задачу с контекстом, заканчивает — закрывает с результатом и файлами. Claude каждого участника видит, что сделали другие, и не повторяет.

Данные комнаты живут в ветке `teamroom` её приватного репозитория на GitHub и синхронизируются раз в 30 секунд. В этом репозитории только код мода.

## Установка

В приложении Claude: кнопка **+** рядом с полем ввода → **Plugins** → **Add marketplace** → `AinurFax/team-room` → **Add plugin** → `team-room`.

В терминале Claude Code:

```
/plugin install team-room --marketplace AinurFax/team-room
```

Из командной строки:

```
claude plugin install team-room --marketplace AinurFax/team-room
```

Нужны git и вход в GitHub на компьютере (например, `gh auth login`, затем `gh auth setup-git`), а для создания комнат — GitHub CLI (`gh`).

## Как пользоваться

- `/teamroom` — открыть панель. Первый раз: имя и компьютер.
- Вкладка «Комнаты»: «Новая комната» (создаёт приватный репозиторий и приглашает людей по нику GitHub) или «Войти в комнату» (адрес репозитория, который тебе прислали).
- Чат подключается к комнате сам, если открыт в её папке проекта, иначе — кнопкой в панели или `/teamroom join <комната>`. Отключить — `/teamroom leave`.
- `/remember <текст>` — записать в общую память, `/task <текст>` — добавить задачу вручную. Обычно это делает Claude сам.
